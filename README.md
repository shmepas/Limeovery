# Limeovery

> **Статус: приложение в разработке.** Возможности и интерфейс могут меняться; некоторые операции требуют проверки на конкретной версии Windows. Используйте на свой риск.

Limeovery — графическая панель системных инструментов для Windows. Она собирает в одном месте сведения о компьютере, дисках и сети, быстрые ссылки на штатные средства Windows, а также инструменты для обслуживания системы.

- **Исходный код:** [GitHub](https://github.com/shmepas/Limeovery)
- **Скачать готовую сборку:** [GitHub Releases](https://github.com/shmepas/Limeovery/releases/latest) — если релиз пока не опубликован, готовой загрузки ещё нет.
- **Требования:** Windows и .NET Framework 4.7.2 или новее.

## Возможности

Состав функций пока не окончательный. Сейчас в приложении есть:

- **Система:** основные сведения о компьютере и быстрый запуск системных оснасток Windows.
- **Диски:** информация о доступных томах, а также ссылки на оптимизацию, очистку и управление дисками.
- **Сеть:** сведения о сетевых подключениях и быстрые команды для диагностики.
- **Процессы:** просмотр и поиск процессов; завершение выбранного процесса и открытие папки с его файлом.
- **Безопасность:** ссылки на Защитник Windows, брандмауэр, просмотр событий, SFC и DISM.
- **Программы и автозагрузка:** просмотр установленных программ и записей автозапуска.
- **Оптимизация и мониторинг:** очистка временных файлов и некоторые системные команды; отображение загрузки процессора и памяти.
- **Реестр:** быстрый доступ к часто используемым разделам.
- **Дополнительные утилиты:** запуск вложенных инструментов из меню «Сторонние утилиты».

## Как пользоваться

1. Скачайте ZIP из [последнего GitHub Release](https://github.com/shmepas/Limeovery/releases/latest) и распакуйте его целиком в отдельную папку.
2. Запустите `Limeovery.exe`. Для обычного просмотра сведений права администратора, как правило, не нужны. Отдельные системные действия сами запросят повышение прав.
3. Выберите нужную вкладку или кнопку. Перед запуском внешней оснастки или команды проверьте её название и параметры.
4. Завершая процесс, редактируя реестр или очищая данные, сначала убедитесь, что выбрали правильный объект.

Не переносите один `Limeovery.exe` отдельно от папок и файлов из архива: приложению нужны вложенные утилиты и другие файлы сборки.

## Сеть и конфиденциальность

При старте текущая версия приложения запускает TCP-сервер на порту **5000**, привязанный ко всем сетевым интерфейсам компьютера (`0.0.0.0`). Кнопка «ПИНГАНУТЬ» отправляет короткое сообщение на заданный адрес; по умолчанию в исходном коде указан `192.168.3.19:5000`. Если порт занят или соединение блокирует брандмауэр, эта функция может не работать.

Используйте сетевые функции только в доверенной сети. Перед запуском проверьте правила Брандмауэра Windows и настройки адреса назначения. Не разрешайте входящие подключения из общедоступных сетей, если вы не понимаете, зачем это требуется.

## Меры предосторожности

Limeovery предоставляет быстрый доступ к операциям, которые могут изменить систему. Наличие кнопки не означает, что действие безопасно для любого компьютера.

- Создайте резервную копию важных файлов. Перед изменением настроек проверьте, включена ли защита системы и доступно ли восстановление.
- Запускайте приложение от имени администратора только для конкретной операции, которой действительно нужны повышенные права.
- **Завершение процесса** может закрыть программу и привести к потере несохранённых данных. Не завершайте незнакомые системные процессы.
- **Реестр и автозагрузка** влияют на запуск Windows и программ. Не удаляйте и не меняйте неизвестные значения.
- **Очистка** временных файлов, корзины, журналов Windows или кеша обновлений удаляет данные. Журналы могут понадобиться для диагностики; удаление загрузочного кеша обновлений может привести к повторной загрузке файлов.
- **Проверка диска** с исправлением ошибок может занять много времени. Перед ней сохраните работу и проверьте резервную копию важных данных.
- **Восстановление MBR** изменяет загрузочные данные диска и может сделать Windows незагружаемой при неправильном выборе системы или диска. Не используйте эту функцию без точного понимания последствий.
- **SFC, DISM, сброс сети и запуск внешних утилит** выполняют штатные команды или сторонние программы с параметрами, которые могут менять конфигурацию Windows. Ознакомьтесь с действием команды и источником утилиты заранее.
- Встроенная функция **восстановления шрифтов** меняет значения реестра и перезапускает Проводник Windows.

Если вы не уверены в результате действия, отмените его и используйте соответствующий инструмент Windows вручную после изучения инструкции Microsoft.

## Сборка и публикация

Проект использует Windows Forms и .NET Framework 4.7.2. Откройте `Limeovery.slnx` или `Limeovery/Limeovery.csproj` в Visual Studio.

GitHub Actions собирает конфигурацию Release и публикует ZIP в Releases при отправке тега версии формата `vX.Y.Z`. Например:

```powershell
git tag v1.0.0
git push origin v1.0.0
```

Архив содержит исполняемый файл и необходимые приложению вложенные ресурсы.
